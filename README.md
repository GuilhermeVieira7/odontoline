# Odontoline — Landing Page

Landing page da Clínica Odontoline (Parauapebas – PA): implantes faciais, mentoplastia e odontologia.

Site estático (HTML + CSS + JS puro), sem build. Todos os botões abrem o WhatsApp **(94) 98121-1643** com mensagem pronta.

## Deploy na Vercel
1. vercel.com → **Add New… → Project**
2. Importe o repositório `GuilhermeVieira7/odontoline`
3. Framework Preset: **Other** · Build e Output vazios
4. **Deploy** — cada `git push` na `main` atualiza o site.

## Editar
- WhatsApp: variável `PHONE` no final do `index.html`
- Imagens: pasta `assets/`
