O que é o implante facial?

É uma prótese facial personalizada que reposiciona e define estruturas do rosto, como queixo e mandíbula. Ela é planejada em 3D a partir dos seus exames, para um resultado harmônico e natural.

Qual a diferença para o preenchimento?

Os preenchedores têm efeito temporário e precisam de reaplicações. O implante facial é um projeto sob medida, pensado para um resultado definitivo.

Como funciona o planejamento?

São quatro etapas: avaliação facial, análise tomográfica, projeto 3D personalizado e o procedimento, com acompanhamento até o resultado final.

O resultado fica natural?

Esse é o objetivo de todo o planejamento. Como o implante é desenhado para a sua anatomia, o resultado acompanha os traços do seu rosto — sem aspecto artificial.

Atendem pacientes de outras cidades?
